3. 3 MASALAH & SOLUSI CV YANG DISEPAKATI TIM
--------------------------------------------------------------------------------
1) Ketersediaan Meja Baca (Seat Occupancy)
   - Problem  : Mahasiswa sering membuang waktu berkeliling hanya untuk mencari
                meja kosong, terutama saat jam sibuk.
   - Solusi CV: Mendeteksi jumlah pengunjung dan kursi kosong di area meja
                (CCTV03 / Mezanin_1, serta area meja Rak_1 & Rak_2) untuk
                menampilkan informasi kapasitas tersedia secara langsung.

2) Deteksi Barang Tertinggal atau Meja Ditinggal Lama (Abandoned Object / Idle Seat)
   - Problem  : Meja sering dibiarkan penuh oleh tas atau laptop tanpa ada
                orangnya dalam waktu lama (booking kursi), sehingga mengurangi
                kapasitas efektif perpustakaan dan berisiko kehilangan barang.
   - Solusi CV: Mendeteksi keberadaan objek (tas/laptop/belonging) di dalam
                zona meja tanpa adanya deteksi orang melewati batas waktu
                tertentu (idle timer berbasis frame rate video).

3) Analisis Kepadatan dan Trafik Lorong Rak Buku (Foot Traffic & Heatmap)
   - Problem  : Staf perpustakaan kesulitan mengetahui area rak buku mana yang
                paling sering dikunjungi atau mengalami penumpukan orang untuk
                kebutuhan penataan ulang tata letak (layout).
   - Solusi CV: Menghitung pergerakan dan kepadatan pengunjung di lorong rak
                buku (CCTV01 / Rak_1 dan CCTV02 / Rak_2) menggunakan titik
                kaki (floor point) untuk memetakan area teramai (heatmap).


4. ARSITEKTUR CLOUD & MODEL COMPUTER VISION SAAT INI
--------------------------------------------------------------------------------
Aplikasi dibangun menggunakan Python + Streamlit (`app.py`) dengan 2 pilihan
backend deteksi yang bisa diganti langsung di sidebar:

A. Mode Utama — Roboflow Cloud Inference (RF-DETR NAS v5 Multi-Angle)
   - Model dilatih di Cloud Roboflow pada 292 gambar multi-angle (CCTV01, CCTV02, CCTV03)
     dengan split 70% Train / 20% Valid / 10% Test.
   - Arsitektur: RF-DETR NAS (dipilih otomatis via Neural Architecture Search).
   - Metrik Test Set di Roboflow (v5 Multi-Angle):
     * mAP@50    : 76.3%
     * Precision : 82.3%
     * Recall    : 62.0%
     * F1 Score  : 67.9%
   - Model ID: terra-yy9jm/prasmul-library-cv-6-rfdetr-nas-t1--b8c736

B. Mode Offline — Hybrid Lokal (YOLO11s + HSV Background Differencing)
   - Model: `yolo11s.pt` (imgsz=960, conf=0.25) + normalisasi cahaya CLAHE.
   - Dilengkapi Layer 2 Fallback HSV: membandingkan channel Hue & Saturation
     area sofa terhadap frame referensi kosong (`config/empty_reference.jpg`),
     kebal terhadap silau matahari jendela (channel Value diabaikan), untuk
     menangkap pengunjung yang menunduk atau tertutup sandaran sofa.

Hasil Uji Perbandingan pada 20 Screenshot `Rak_1`:
- YOLO11s Pretrained   : 79 orang terdeteksi  | 23 meja terisi terdeteksi.
- Roboflow RF-DETR NAS : 135 orang terdeteksi | 30 meja terisi terdeteksi
                         (+70.9% deteksi orang, +30.4% deteksi meja terisi).


5. STRUKTUR FOLDER & FILE PENTING
--------------------------------------------------------------------------------
- `app.py`                         : Aplikasi dashboard utama Streamlit.
- `src/detector.py`                : Modul deteksi (Roboflow RF-DETR NAS & YOLO11s).
- `src/seat_monitor.py`            : Logika ROI poligon meja, timer idle, & HSV fallback.
- `src/traffic_heatmap.py`         : Akumulator heatmap pergerakan pengunjung lorong.
- `src/ui_styles.py`               : Tema UI terang/gelap (Light/Dark Mode).
- `config/table_zones.json`        : Koordinat poligon meja per profil kamera.
- `config/empty_reference.jpg`     : Referensi gambar kosong untuk HSV fallback.
- `scripts/evaluate_screenshots.py`: Script evaluasi batch -> menghasilkan CSV & gambar.
- `scripts/select_roi.py`          : Tool gambar ulang poligon zona meja secara interaktif.
- `scripts/extract_media.py`       : Tool potong video & ekstrak screenshot dari CCTV.
- `scripts/auto_label.py`          : Tool auto-labeling format YOLO (.txt).
- `tests/verify_app.py`            : Suite pengujian otomatis (9/9 test PASS).


6. CARA MENJALANKAN DI LAPTOP ANGGOTA TIM
--------------------------------------------------------------------------------
1) Clone repo & masuk ke folder:
   git clone https://github.com/Earthen8/prasmul-library-cv.git
   cd prasmul-library-cv

2) Buat virtual environment & install library:
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt

3) Setup API Key Roboflow:
   Salin `.env.example` menjadi `.env`, lalu isi `ROBOFLOW_API_KEY=...`
   (minta API key ke anggota tim, atau masukkan langsung di sidebar aplikasi).

4) Jalankan aplikasi demo Streamlit:
   .venv\Scripts\streamlit.exe run app.py

5) Jalankan unit test verifikasi:
   .venv\Scripts\python.exe -m tests.verify_app
